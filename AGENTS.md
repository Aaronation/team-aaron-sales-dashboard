# Agent notes

Phase 1 is the weekly manager review (week picker, same calendar dates last month, rep / customer / SKU review, line detail, HKD). Phase 2 adds monthly totals, the sell-out pie, and hand import. Phase 3 keeps that working set in the browser (IndexedDB for the lines, localStorage for the review filters) and adds monthly target vs MTD, pace, and a working-day forecast. Later phases keep all of this. Kingdee auto-sync stays deferred.

## Standing rules

- Keep Phase 1 features when adding a later phase. Do not drop the weekly review to make room for the next chart.
- Soft Earth tokens live in `src/lib/palette.ts` (`INK`, `TAUPE`, `OLIVE`, `AMBER`, `CLAY`, `SAGE`, `CREAM`). Use that palette. Do not invent a second theme.
- Charts use Customer Name (`customer`, short labels), not the raw 往来单位 string. On **Merge into current**, `mergeImportedItems` applies `src/lib/partnerAliases.ts` (wGAL map) so `駿業電腦用品公司 Vision computer` becomes **Vision** when the sheet has no separate short name. An explicit 客户 / Customer Name column wins. Customer groups also share one identity when labels differ only by whitespace (including full-width spaces) or letter case, so `YOHO友和` and `YOHO 友和` are one customer shown as `YOHO 友和`. That rule does not merge other legal-form suffixes (`Something` stays distinct from `Something Limited`). Aaron’s named CTM group is the exception: `CTM`, `CTM Limited`, and `澳門電訊股份有限公司` display as `CTM`. `星馳通訊器材` is excluded from ingest, Merge, and every total, including whitespace and letter-case variants of that name.
- **Merge into current** is invoice-aware. For each invoice number in the file, `mergeImportedItems` replaces that invoice’s working-set lines with the file’s lines (revised qty, price, date, SKU set, customer label, or dropped lines). Invoices the file does not mention stay, so a partial export does not wipe them. Repeated identical lines on one invoice stay (Kingdee’s document total counts each; SI26110098 lists IP116AM twice at HK$180). Importing that invoice again replaces the set, so the same file does not stack. Rows with no invoice number still dedupe. **Replace all** still replaces the whole working set. Partner alias rematch still runs on Merge only.
- Hong Kong working days come from `src/lib/hkHolidays.ts`. `isWorkingDay` excludes weekends and gazetted HK holidays. Do not count those days as working days.
- Ship as draft pull requests. Merge to `main` only after Aaron’s explicit go.
- No Kingdee auto-sync until Aaron opens that phase. Hand import stays on `ingestRecords` and `mergeImportedItems`. A future sync should call that mapper instead of growing a second one.
